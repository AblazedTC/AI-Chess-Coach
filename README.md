# Chess Coach

A fresh, independent rebuild of a chess analysis and coaching application.

The application imports Chess.com games, replays positions, analyzes with
Stockfish, and provides explanations grounded in verified chess evidence.
An offline demo will run without API keys or network access.

## Development

Implementation is underway on feature branches in separate git worktrees.
Pull requests will include automated checks and verification results.

The original project and submission materials are not part of this repository.
